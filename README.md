# Arkenfall-Game

This is a text-based fantasy RPG inspired by DnD dice roll mechanics.

Status: Currently unfinished and a work in progress. Currently only the character
creation and opening of chapter one is playable. The combat system is partly built
and runs after the current lines of chapter one runs out.

How it works: Type your choices when prompted and press [ENTER] to advance
the story.

Features

Character creation:
- Difficulty sets the base stats: Easy (9 for each stat), Normal (8), Hard (7).
- 8 races: Human, Elf, Dwarf, Halfling, Orc, Gnome, Tiefling, Lizardfolk.
- 7 classes: Fighter, Rogue, Wizard, Cleric, Paladin, Ranger, Monk.
- 6 stats: STR, DEX, CON, INT, WIS, CHA – these are adjusted by race and
  class.
- Class decides the weapon proficiency, starting weapon, and starting spells (if
  Wizard, Cleric, or Paladin)

Combat (currently in development):
- Attack roll: d20 roll + stat modifier + proficiency + weapon rarity/magic master
  + attack modifier need to be higher than enemy AC (armour class).
- Natural 20 = critical hit.
- Natural 1 = critical miss.
- Damage roll: d6 roll + the same bonuses.
- 14 weapons, each with five attack styles (balanced, precise, heavy, reckless,
  signature) that trade accuracy for damage.
- 16 spells across two magic schools (arcane and divine) which are split into
  starter and learnable spells with mana costs.

Story:
- Chapter one: Woken by a nervous old man that will give the user the main
  quest and set the overarching goal of the program.
- To be continued. The user will progress through the story fighting enemies till
  they reach the end goal. The program will be split into chapters, and each
  chapter will end at the same point. If the character dies, the game ends. Other
  stats like CHA will be used in conversations to avoid confrontations or
  persuade people (e.g. get a better reward).
  
Note: This project was to really test myself and see if I could try to use a lot of
  different techniques I’ve learned and bring them into one project. The code has been
  through a lot of stages since I began, and I’ve had to change a lot because I knew
  less than I do now. The project will need a lot more work to become a neat complete
  project. If you want a smaller project like a quick card game that will be completed a
  lot sooner, I’m happy to try and create another project as the capstone and continue
  this one as a passion project.
